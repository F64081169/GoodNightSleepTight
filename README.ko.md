# 작식회정 · Good Night Sleep Tight

[English](README.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · **한국어**

> 매일 조금씩, **23:00에 자고 08:00에 일어나는** 생활로.

작식회정(作息回正, '생활 리듬을 바로잡는다'는 뜻)은 체내 시계가 늦게 밀려 버린 사람을 위한 작은 웹 앱입니다. 새벽 2시가 넘어야 잠들고, 아침 10시 반에야 겨우 일어나며, '일찍 자야지' 마음먹어도 잘 안 되는 분을 위해 만들었습니다. 목표 시간으로 한 번에 맞추라고 하지 않습니다. 잠자리에 드는 시간과 일어나는 시간을 15분씩 앞당기고, 몸이 실제로 따라왔을 때만 다음 단계로 넘어갑니다.

가입도 서버도 없습니다. 앱은 HTML 파일 하나뿐이고, 데이터는 내 휴대폰 안에만 저장됩니다.

## 왜 조금씩일까요?

체내 시계는 하루에 15~30분 정도만 안정적으로 옮길 수 있습니다. 한 번에 3시간을 앞당기면 시차 적응과 똑같은 일이 생깁니다. 누워도 잠이 안 오고, 답답해지고, 결국 포기하게 됩니다. 이 앱은 수면 리듬이 늦게 밀린 경우에 쓰는 표준 행동 요법 원칙을 따릅니다.

| 원칙 | 앱에서 하는 일 |
|---|---|
| **점진적 앞당기기** | 취침·기상 시간을 한 번에 작은 한 걸음만 앞당기고, 따라오면 다음으로 넘어갑니다. |
| **기상 시간이 기준점** | 전날 밤 잠을 설쳐도 정해진 시간에 일어납니다. 그래야 그날 밤 자연스럽게 졸립니다. |
| **취침 시간은 '가장 이른' 시간** | 졸릴 때 눕습니다. 깬 채로 오래 누워 있으면 불면이 학습됩니다. |
| **아침 햇빛** | 일어나자마자 밖에서 20~30분 보냅니다. 시계를 앞당기는 가장 강한 신호입니다. |
| **밤에는 어둡게** | 취침 2시간 전에 조명을 낮추고, 45분 전에는 휴대폰을 내려놓습니다. |
| **카페인·낮잠 마감** | 취침 8시간 전부터는 카페인도 낮잠도 피합니다. 낮잠은 20분 이내로 합니다. |
| **자극 조절법(CBT-I)** | 20분이 지나도 잠이 안 오면 일어나 어두운 곳에서 지루한 일을 하다가, 졸리면 다시 눕습니다. |

### 언제 한 걸음 나아가나요?

매일 아침 두 번 탭해서 두 가지 질문에 답합니다.

| 오늘 기상 | 30분 안에 잠듦 | 30분 넘게 걸림 | 늦게 누움 |
|---|---|---|---|
| **제시간**(앞뒤 15분 이내) | ✅ 한 걸음 전진 | ⏸ 제자리 | ⏸ 제자리 |
| **15~30분 늦음** | ⏸ 제자리 | ⏸ 제자리 | ⏸ 제자리 |
| **30분 넘게 늦음** | ⏸ 제자리(늦잠) | ⏸ 제자리(늦잠) | ⏸ 제자리(늦잠) |

잠드는 데 오래 걸린다는 건 체내 시계가 아직 따라오지 못했다는 신호입니다. 그래도 밀어붙이면 깬 채로 누워 있는 시간만 늘어나기 때문에, 계획은 잠시 기다립니다.

### 속도

| 속도 | 한 걸음 | 예: 02:00 / 10:30 → 23:00 / 08:00 |
|---|---|---|
| 느리게 | 2일마다 15분 | 약 24일 |
| **보통**(추천) | 매일 15분 | 약 12일 |
| 빠르게 | 매일 30분 | 약 6일 |

속도는 언제든 바꿀 수 있고, 지금까지의 진행 상황은 그대로 유지됩니다.

## 주요 기능

- **오늘 밤 계획을 한눈에:** 오늘 밤 가장 이른 취침 시간과 내일 아침 기상 시간을 큰 글씨로 보여 줍니다. 24시간 다이얼에서 수면 시간대와 목표를 함께 볼 수 있습니다.
- **하루 타임라인:** 기상, 아침 햇빛, 아침 식사, 카페인·낮잠 마감, 운동 마감, 조명 낮추기, 긴장 풀기, 취침. 모든 시간은 오늘 밤 계획에서 계산되며, 끝낸 항목은 탭해서 체크합니다.
- **'다음 할 일' 카운트다운:** 웹 페이지는 푸시 알림을 보낼 수 없으므로, 화면 맨 위에 다음 할 일과 남은 시간을 항상 보여 줍니다.
- **아침 기록은 두 번 탭:** 기상 상태, 잠든 상태 순서로 고르면 자동으로 저장됩니다. 5초 안에 되돌릴 수 있고, 그날 안에는 수정도 할 수 있습니다. 정확한 시간으로 기록하고 싶다면 입력 모드로 바꿔 잠자리에 든 시간, 잠든 시간, 일어난 시간을 넣으세요. 같은 규칙으로 판정해 저장하기 전에 결과를 보여 줍니다.
- **올빼미형에 맞춘 '하루' 구분:** 날짜는 예정 기상 3시간 전에 바뀝니다. 새벽 0시 30분에 열어도 내일이 아니라 '오늘 밤'이 보입니다.
- **실패에 너그러운 설계:**
  - 3일 연속 늦잠을 자면 한 단계 뒤로 물러나기를 제안합니다.
  - 3일 이상 쉬고 돌아오면 '다시 오신 걸 환영해요' 카드가 나타나, 한 단계 물러나 몸을 다시 맞추도록 권합니다.
  - 목표에 도달한 뒤에도 리듬이 다시 늦어지기 시작하면 알려 줍니다.
- **안전 확인:**
  - 12시간제 휴대폰에서 오전·오후를 잘못 고른 것 같으면 먼저 확인을 요청합니다.
  - 낮에 잠드는 일정이면, 교대 근무 때문인 경우가 많고 이 계획은 교대 근무에 맞지 않는다고 안내합니다.
  - 차이가 매우 크면 수면 전문의 상담을 권합니다.
  - 졸릴 때는 운전하지 말라는 안내도 보여 줍니다.
- **늦추는 방향도 지원:** 목표가 지금보다 늦은 시간이면 빛에 관한 조언이 반대로 바뀝니다. 아침 햇빛을 피하고, 저녁에 빛을 쬡니다.
- **진행 상황과 기록:** 제시간 기상 연속 일수, 최근 7일 달성률, 현재 단계, 결과별로 색을 입힌 취침 시간 그래프, 최근 기록 목록을 보여 줍니다.
- **목표 달성:** 캡처하기 좋은 달성 카드와, 친구에게 보낼 수 있는 소개 문구를 준비해 둡니다.
- **백업 코드:** 문자열 하나만 복사하면 새 휴대폰이나 브라우저로 데이터를 옮길 수 있습니다. 아이폰 Safari처럼 오래 열지 않은 사이트의 데이터를 지우는 브라우저가 있어서, 일주일에 한 번 백업을 권합니다.
- **라이트·다크 모드**, 모바일 우선 레이아웃, 키보드 조작, 잘 보이는 포커스 표시를 지원합니다.

## 사용 방법

1. **첫날:** 평소 잠드는 시간과 일어나는 시간을 입력합니다. 목표(23:00 / 08:00)와 속도는 미리 채워져 있으며, 바꾸려면 '修改'(수정)를 누릅니다. 오늘 밤은 평소대로 주무세요.
2. **매일 아침:** 앱을 열고 두 번 탭합니다. 오늘 아침 기상 상태와 어젯밤 잠든 상태입니다. 계획을 따라왔다면 오늘 밤 시간이 한 걸음 앞당겨집니다.
3. **낮 동안:** 타임라인을 따라 지냅니다. 가장 중요한 것은 아침 햇빛과 카페인 마감입니다.
4. **매일 밤:** 조명을 낮출 시간과 누워도 되는 시간을 카운트다운이 알려 줍니다. 아직 졸리지 않으면 조금 더 기다리세요.
5. **일주일에 한 번:** '紀錄'(기록) 탭에서 백업 코드를 복사합니다.

## 개인정보

- 계정도, 분석 도구도, 서버도 없습니다. 모든 데이터는 내 기기 브라우저의 `localStorage`에만 저장됩니다.
- 링크를 보내 준 친구는 내 데이터를 볼 수 없고, 나도 친구의 데이터를 볼 수 없습니다.
- 외부로 나가는 요청은 Google Fonts 글꼴을 불러오는 것뿐입니다. 글꼴이 차단되면 시스템 글꼴로 표시됩니다.

## 직접 배포하기

정적 파일 하나뿐이라 빌드도, 의존성도 없습니다.

- **GitHub Pages:** *Settings → Pages → Build and deployment*에서 Source를 *Deploy from a branch*로 바꾸고, `main`과 `/ (root)`를 선택해 저장합니다. 1분쯤 지나면 `https://<사용자명>.github.io/GoodNightSleepTight/` 에서 열립니다.
- **그 밖의 방법:** `index.html`을 아무 정적 호스팅(Netlify, Cloudflare Pages, Vercel, 개인 서버 등)에 올리거나, 내 컴퓨터에서 바로 엽니다.

## 기술 메모

- `index.html` 하나에 HTML, CSS, 순수 JavaScript를 담았습니다. 프레임워크도 번들러도 쓰지 않습니다.
- **위치 기반 데이터 모델:**
  - `origin`: 처음 시작한 리듬.
  - `pos`: 오늘 밤 취침과 내일 아침 기상.
  - `tgt`: 목표.
  - 전진하면 `pos`가 `tgt` 쪽으로 한 걸음 가고, 물러나면 `origin` 쪽으로 돌아갑니다. 그래서 속도를 바꿔도 진행 상황이 초기화되지 않습니다.
- 기록할 때마다 기록 전 상태를 저장하므로, 수정하거나 되돌릴 때 정확히 복원됩니다.
- 데이터를 불러올 때와 백업에서 복원할 때 형식을 검사합니다. 데이터가 손상되어도 빈 화면 대신 초기화 옵션을 보여 줍니다.

## 만든 과정

이 앱은 Anthropic의 Claude를 이용해 Claude Code에서 설계하고 개발했습니다. 그다음 두 AI 에이전트가 세 차례 리뷰했습니다.

- **UX 리서처 역할:** 휴대폰으로 링크를 처음 연 친구와, 2주째 사용 중인 사용자를 가정했습니다.
- **수면 교육 전문가 역할:** CBT-I(불면증 인지행동치료)와 일주기 리듬에 밝은 입장입니다.

매 라운드마다 두 에이전트가 당시 버전을 두고 토론해 우선순위를 매긴 개선 목록에 합의했고, 개선 사항은 휴대폰 화면 폭에서 직접 테스트했습니다.
