# 作息回正 · Good Night Sleep Tight

[English](README.md) · [繁體中文](README.zh-TW.md) · **日本語** · [한국어](README.ko.md)

> 毎日少しずつ、**23:00 就寝・08:00 起床**の生活リズムへ。

「作息回正」（生活リズムを元に戻す、という意味）は、体内時計が後ろにずれてしまった人のための小さな Web アプリです。夜中の 2 時まで眠れない、朝は 10 時半まで起きられない、「早く寝よう」と思ってもうまくいかない、そんな人に向けています。いきなり目標の時刻に合わせることは求めません。就寝と起床を 15 分ずつ早めていき、体が本当に追いついてから次へ進みます。

登録もサーバーもありません。アプリは HTML ファイル 1 つだけで、データはあなたのスマホの中だけに保存されます。

## なぜ少しずつなのか

体内時計が安定して動かせるのは、1 日に 15〜30 分程度です。いきなり 3 時間早めると、時差ぼけと同じことが起きます。布団に入っても眠れず、焦り、やがてあきらめてしまいます。このアプリは、睡眠リズムが後ろにずれた状態への標準的な行動療法の考え方に沿って作られています。

| 原則 | アプリでの扱い |
|---|---|
| **段階的な前進** | 就寝・起床を一度に小さく一歩だけ早め、できたら次へ進みます。 |
| **起床時刻が基準** | 前の晩によく眠れなくても予定どおり起きます。そうすると夜に自然と眠くなります。 |
| **就寝時刻は「最も早い」時刻** | 眠くなってから布団に入ります。眠れないまま横になり続けると、不眠を学習してしまいます。 |
| **朝の光** | 起床後すぐ屋外で 20〜30 分過ごします。体内時計を前に進める最も強い合図です。 |
| **夜は暗めに** | 就寝 2 時間前に照明を落とし、45 分前にはスマホを置きます。 |
| **カフェイン・昼寝の締め切り** | 就寝 8 時間前からはカフェインも昼寝も控えます。昼寝は 20 分までです。 |
| **刺激制御法（CBT-I）** | 20 分眠れなければ布団を出て、薄暗い場所で退屈なことをし、眠くなったら戻ります。 |

### いつ一歩進むのか

毎朝 2 回タップして、2 つの質問に答えます。

| 今朝の起床 | 30 分以内に寝つけた | 30 分以上かかった | 遅めに寝た |
|---|---|---|---|
| **予定どおり**（前後 15 分以内） | ✅ 一歩前進 | ⏸ その場で待つ | ⏸ その場で待つ |
| **15〜30 分遅れ** | ⏸ その場で待つ | ⏸ その場で待つ | ⏸ その場で待つ |
| **30 分以上遅れ** | ⏸ その場で待つ（寝坊） | ⏸ その場で待つ（寝坊） | ⏸ その場で待つ（寝坊） |

寝つきに時間がかかるのは、体内時計がまだ追いついていないサインです。それでも先へ進めると、布団の中で起きている時間が長くなるだけなので、計画はいったん待ちます。

### ペース

| ペース | 1 ステップ | 例：02:00 / 10:30 → 23:00 / 08:00 |
|---|---|---|
| ゆっくり | 2 日ごとに 15 分 | 約 24 日 |
| **標準**（おすすめ） | 毎日 15 分 | 約 12 日 |
| 速め | 毎日 30 分 | 約 6 日 |

ペースはいつでも変更でき、それまでの進み具合はそのまま残ります。

## 主な機能

- **今夜の予定がひと目でわかる：** 今夜の最も早い就寝時刻と明朝の起床時刻を大きく表示します。24 時間ダイヤルで、睡眠時間帯と目標を並べて確認できます。
- **1 日のタイムライン：** 起床、朝の光、朝食、カフェイン・昼寝の締め切り、運動の締め切り、照明を落とす、リラックス、就寝。どの時刻も今夜の計画から計算され、終わったらタップでチェックできます。
- **「次にやること」カウントダウン：** Web ページはプッシュ通知を送れないため、画面の一番上に次の行動と残り時間を常に表示します。
- **朝の記録は 2 タップ：** 起床の様子、寝つきの順に選ぶと自動で送信されます。5 秒以内なら取り消せて、その日のうちは修正もできます。
- **夜型に合わせた「1 日」の区切り：** 日付が変わるのは予定起床の 3 時間前です。深夜 0 時半に開いても、表示は明日ではなく「今夜」のままです。
- **失敗に寛容：**
  - 3 日続けて寝坊すると、一段階戻ることを提案します。
  - 3 日以上空いたあとは「おかえりなさい」カードを出し、一段階戻って慣らすことを勧めます。
  - 目標に到達したあとも、リズムが後ろに戻り始めたら知らせます。
- **安全のための確認：**
  - 12 時間表示のスマホで午前と午後を取り違えていそうなときは、まず確認を求めます。
  - 就寝が日中になっている場合は、交代勤務が原因のことが多く、この計画は合わないと伝えます。
  - ずれが非常に大きいときは、睡眠専門医への相談を勧めます。
  - 眠いときは運転しないよう注意も表示します。
- **遅らせる方向にも対応：** 目標が今より遅い時刻なら、光の助言が逆になります。朝の光を避け、夕方に光を浴びます。
- **進み具合と記録：** 予定どおり起きた連続日数、直近 7 日の達成率、現在の段階、結果ごとに色分けした就寝時刻のグラフ、最近の記録一覧を表示します。
- **目標達成：** スクリーンショット向けの達成カードと、友だちに送れる紹介文を用意します。
- **バックアップコード：** 文字列を 1 つコピーするだけで、新しいスマホやブラウザにデータを移せます。iPhone の Safari など、しばらく開いていないサイトのデータを消すブラウザがあるため、週に一度バックアップを促します。
- **ライト／ダークモード**、スマホ優先のレイアウト、キーボード操作、見やすいフォーカス表示に対応しています。

## 使い方

1. **1 日目：** いつもの就寝・起床時刻を入力します。目標（23:00 / 08:00）とペースは入力済みです。変更するときは「修改」（編集）をタップします。今夜はいつもどおりの時間に寝てください。
2. **毎朝：** アプリを開いて 2 回タップします。今朝の起床の様子と、昨夜の寝つきです。予定どおりなら、今夜の時刻が一歩早まります。
3. **日中：** タイムラインに沿って過ごします。特に大切なのは朝の光とカフェインの締め切りです。
4. **毎晩：** 照明を落とす時刻と、布団に入ってよい時刻をカウントダウンが知らせます。まだ眠くなければ、もう少し待ちましょう。
5. **週に一度：** 「紀錄」（記録）タブでバックアップコードをコピーします。

## プライバシー

- アカウント不要で、アクセス解析もサーバーもありません。データはすべて、あなたの端末のブラウザの `localStorage` にだけ保存されます。
- リンクを送ってくれた友だちにあなたのデータは見えませんし、あなたにも友だちのデータは見えません。
- 外部への通信は、Google Fonts のフォント読み込みだけです。フォントがブロックされた場合は、システムフォントで表示されます。

## 自分で公開する

静的ファイル 1 つだけで、ビルドも依存パッケージもありません。

- **GitHub Pages：** *Settings → Pages → Build and deployment* で、Source を *Deploy from a branch* にし、`main` と `/ (root)` を選んで保存します。1 分ほどで `https://<ユーザー名>.github.io/GoodNightSleepTight/` に公開されます。
- **その他：** `index.html` を任意の静的ホスティング（Netlify、Cloudflare Pages、Vercel、自前のサーバーなど）に置くか、手元のファイルを直接開いてください。

## 技術メモ

- `index.html` 1 つに HTML・CSS・素の JavaScript をまとめています。フレームワークもバンドラーも使っていません。
- **位置ベースのデータモデル：**
  - `origin`：開始時点のリズム。
  - `pos`：今夜の就寝と明朝の起床。
  - `tgt`：目標。
  - 前進すると `pos` が `tgt` に一歩近づき、後退すると `origin` 側へ戻ります。このため、ペースを変えても進み具合はリセットされません。
- 記録のたびに記録前の状態を保存するので、修正や取り消しで正確に元へ戻せます。
- 読み込み時とバックアップ復元時にデータを検証します。データが壊れていても真っ白な画面にはならず、初期化の選択肢を表示します。

このアプリは、Anthropic の Claude を使い、Claude Code で設計・開発しました。その後、2 つの AI エージェントによるレビューを 3 回行いました。

- **UX リサーチャー役：** 初めてスマホでリンクを開いた友だちと、使い始めて 2 週間のユーザーを想定しました。
- **睡眠教育の専門家役：** CBT-I（不眠症の認知行動療法）と概日リズムに詳しい立場です。

毎回 2 人がその時点の版について議論し、優先順位をつけた改善リストで合意しました。改善はスマホ幅で実際に動かして確認しています。

## 免責事項

本ツールは一般的な睡眠衛生の情報を提供するもので、**医療上の助言ではありません**。医師の診断や治療に代わるものではありません。

次のような場合は、睡眠専門医や心療内科に相談してください。
- 週 3 日以上の不眠が 3 か月以上続いている。
- 大きないびきや、睡眠中の呼吸の停止を指摘された。
- 日中の強い眠気が運転や仕事に影響している。
- 何をしても生活リズムが後ろにずれ続ける。
- 気分の落ち込みが長く続いている。

メラトニンは体内時計の調整に役立つことがありますが、国によっては（台湾など）処方薬です。用量と飲むタイミングは医師に相談してください。
